SSK Database Mapping (English + Armenian)
=========================================

This file describes the logical schema. The live database may also receive **automatic migrations** when the app boots (`includes/db.php`) — e.g. adding `role`, `slug`, or `name_i18n` on older snapshots. For a clean install, use `database/database_schema.sql` plus app first run.

Core Connection
---------------
Database name: `ssk`
Host: `127.0.0.1`
User: `ssk_app`
Password: provided from environment variable `DB_PASSWORD` (not stored in repository)
Charset: `utf8mb4`


1) users - օգտատերեր
--------------------
Purpose: Stores login and role data.

CREATE TABLE IF NOT EXISTS users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    role VARCHAR(50) DEFAULT 'user',
    email VARCHAR(255) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);


2) categories - կատեգորիաներ
----------------------------
Purpose: Master list of book categories.

Physical columns in MySQL (this table does NOT use six separate VARCHAR columns for languages):

- `id`: primary key.
- `name`: canonical label (unique). The app keeps this aligned with the English display string (`name_i18n.en`) when admins save categories.
- `slug`: stable ASCII key for filters, URLs, and APIs (unique after migration). Example: `business`, `science-fiction`.
- `name_i18n`: a **single TEXT** column storing **one JSON object**. That object has **six string keys** — one per UI language — not six DB columns:
  - `en` — English
  - `hy` — Armenian (Հայերեն)
  - `ru` — Russian
  - `fr` — French
  - `de` — German
  - `it` — Italian

Rules in code (`includes/category_i18n.php`):

- The visitor’s session language (`sskCurrentLang()`) picks `name_i18n[lang]` when it is non-empty.
- If that key is empty, the UI falls back to another filled key (English preferred), then to `categories.name`.
- Admin UI (`admin/categories.php`) edits all six keys; saving runs `UPDATE categories SET name = ?, slug = ?, name_i18n = ?`.

Example JSON value (pretty-printed for humans; stored as one line in MySQL):

```json
{
  "en": "Science Fiction",
  "hy": "Գիտական ֆանտաստիկա",
  "ru": "Научная фантастика",
  "fr": "Science-fiction",
  "de": "Science-Fiction",
  "it": "Fantascienza"
}
```

Bulk seed for the default genre list (local or server DB): from project root run  
`php scripts/backfill-category-translations.php`  
(see `README.md` §5).

CREATE TABLE IF NOT EXISTS categories (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(255) NOT NULL UNIQUE,
    slug VARCHAR(191) NULL,
    name_i18n TEXT NULL
);


3) books - գրքեր
----------------
Purpose: Book catalog uploaded by admins/users, linked to owner and category.

CREATE TABLE IF NOT EXISTS books (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    title VARCHAR(255) NOT NULL,
    author VARCHAR(255) NOT NULL,
    description TEXT NULL,
    cover_url VARCHAR(255) NULL,  -- local path uploads/... or vetted https:// image URL (see sskNormalizeStoredCoverUrl in includes/db.php)
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    category_id INT NULL,
    isbn VARCHAR(20) NULL,
    publisher VARCHAR(255) NULL,
    publish_year INT NULL,
    language VARCHAR(100) DEFAULT 'English',
    page_count INT NULL,
    author_bio TEXT NULL,
    format VARCHAR(100) NULL,
    edition VARCHAR(100) NULL,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (category_id) REFERENCES categories(id) ON DELETE SET NULL
);


4) user_books - օգտատիրոջ ընթերցման կարգավիճակ
----------------------------------------------
Purpose: Junction table for each user's reading status and favorites.

CREATE TABLE IF NOT EXISTS user_books (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    book_id INT NOT NULL,
    status ENUM('want_to_read', 'reading', 'read') DEFAULT 'want_to_read',
    is_favorite TINYINT(1) DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY unique_user_book (user_id, book_id),
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (book_id) REFERENCES books(id) ON DELETE CASCADE
);


5) site_settings - կայքի կարգավորումներ
---------------------------------------
Purpose: About-page and site text content editable from admin panel.

CREATE TABLE IF NOT EXISTS site_settings (
    setting_key VARCHAR(255) PRIMARY KEY,
    setting_value TEXT NULL,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
